# Al-Noor Clinic - Free Demo Concept Website

This is a **free demo concept website** for **Al-Noor Clinic** (medical clinic), located at C7WX+RXJ, Shah Jelani Rd, Township, Lahore, Punjab. It was created by a Lahore web designer to show what a professional website for the business could look like, before they order one.

**Important:** This is NOT the business's official website. All contact details, services, and timings shown are illustrative demo content, not verified facts about the business. The phone number +92 300 0000000 is a placeholder demo number.

## What's inside

- Hero with floating info cards and WhatsApp CTA
- Services grid: General Checkups, First Aid, BP & Sugar Monitoring, Immunization, Minor Procedures, Health Certificates
- Sample morning/evening OPD timings table
- Appointment request form (demo, no data sent)
- CTA band with call/WhatsApp buttons
- Contact section with address, placeholder phone, map link, callback form

## Run

Open `index.html` in any browser. Fully self-contained: no external images, works offline.
